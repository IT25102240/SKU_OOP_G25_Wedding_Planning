 **Wedding Planning and Vendor Booking System**  

 📖 Overview 
 
The **Wedding Booking System** is an all‑in‑one sales and marketing platform designed for wedding venues and vendors. It centralizes inquiries, communication, scheduling, payments, contracts, and analytics to streamline operations, reduce manual work, and increase bookings.  



 ✨ Features

- **User Management** – Register, login, and manage user profiles.  - Vidura
- **Wedding Package Management** – Create, update, and manage wedding packages.  - Lahiru
- **Booking Management** – Handle reservations, confirmations, and cancellations.  - Daham
- **Payment Handling** – Secure payment processing and tracking.  - Daham
- **Feedback & Review Management** – Collect and display customer feedback.  - Chanuka
- **Analytics Dashboard** – Generate insights on bookings and revenue.  - Vidura



🛠️ Tech Stack
 
- **Languages:** Java (OOP principles), HTML, CSS  
- **Frameworks/Tools:** Apache Tomcat, GitHub  
- **Database:** MySQL  
- **Version Control:** Git & GitHub  



🚀 Installation & Setup
 
1. Clone the repository:  
   ```bash
   git clone https://github.com/IT25102240/SKU_OOP_G25_Wedding_Planning.git
   ```  
2. Import the project into your IDE (e.g., IntelliJ, Eclipse).  
3. Configure the database connection in `config.properties`.  
4. Deploy on **Apache Tomcat** server.  
5. Access the system via `http://localhost:8080/WeddingBookingSystem`.  



🎯 Usage
 
- **Customers** can browse packages, make bookings, and provide feedback.  
- **Vendors/Admins** can manage packages, track payments, and view analytics.
